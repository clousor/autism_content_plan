## 1. The Three-Tier Measurement Framework

To prevent vanity metrics from misleading strategic decisions, performance is tracked across three distinct, mutually reinforcing tiers:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     THE 3-TIER KPI MEASUREMENT MATRIX                   │
├────────────────────┬────────────────────┬───────────────────────────────┤
│ TIER 1: ORGANIC    │ TIER 2: PAID MEDIA │ TIER 3: BUSINESS CONVERSION   │
│ ATTENTION & HEALTH │ EFFICIENCY & REACH │ & COMMERCIAL IMPACT           │
├────────────────────┼────────────────────┼───────────────────────────────┤
│ • Total Reach      │ • Total Ad Spend   │ • Direct Phone Inquiries      │
│ • Non-Follower %   │ • Blended CPM      │ • WhatsApp Lead Conversations │
│ • 3s Hold Rate     │ • Cost / ThruPlay  │ • Evaluation Appointments     │
│ • Completion Rate  │ • Profile Visits   │ • Centre Walk-in Visits       │
│ • Shares / Reach   │ • Cost / Follower  │ • Google Maps Directions      │
│ • Saves / Reach    │ • Retargeting ROAS │ • Branded Google Searches     │
│ • Follows / 1K Vw  │ • Ad Frequency     │ • Inquiry-to-Intake %         │
└────────────────────┴────────────────────┴───────────────────────────────┘
```

### Detailed Metric Definitions & Target Benchmarks:

| Metric Name | Calculation / Formula | Minimum Acceptable | Target Benchmark | Outlier Winner |
| :--- | :--- | :--- | :--- | :--- |
| **Share-to-Reach Ratio** | $\frac{\text{Direct Shares}}{\text{Total Accounts Reached}} \times 100$ | 1.8% | **3.5%** | > 5.5% |
| **Save-to-Reach Ratio** | $\frac{\text{Saves}}{\text{Total Accounts Reached}} \times 100$ | 2.5% | **4.5%** | > 7.0% |
| **3-Second Hold Rate** | $\frac{\text{3-Second Views}}{\text{Total Video Impressions}} \times 100$ | 48% | **65%** | > 75% |
| **Watch Completion Rate** | $\frac{\text{100% Video Completions}}{\text{Video Starts}} \times 100$ | 18% | **28%** | > 38% |
| **Profile Visit Rate** | $\frac{\text{Profile Visits}}{\text{Reel Reach}} \times 100$ | 2.0% | **3.2%** | > 4.5% |
| **Follow Conversion Rate** | $\frac{\text{New Follows}}{\text{Profile Visits}} \times 100$ | 6.5% | **9.5%** | > 12.0% |
| **Follows per 1K Views** | $\frac{\text{Follows Attributable}}{\text{Total Video Views}} \times 1,000$ | 2.5 | **4.8** | > 7.0 |
| **Blended Meta CPM** | $\frac{\text{Total Paid Spend}}{\text{Total Paid Impressions}} \times 1,000$ | < ₹160 | **₹115 – ₹140** | < ₹100 |
| **Cost Per Meaningful View**| $\frac{\text{Paid Spend}}{\text{ThruPlays (15s+) views}}$ | < ₹0.45 | **₹0.18 – ₹0.28**| < ₹0.14 |
| **Cost Per Qualified Lead** | $\frac{\text{Total Spend}}{\text{Verified Parent Enquiries}}$ | < ₹2,200 | **₹1,400 – ₹1,800**| < ₹1,100 |

## 2. The Weekly Growth Review Protocol (Every Monday)

Every Monday morning at 10:00 AM, the Strategy, Creative, and Clinic Intake teams meet for a strict 30-minute **Growth Audit**. The meeting is governed by answering these 14 diagnostic questions:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     WEEKLY DIAGNOSTIC AUDIT CHECKLIST                   │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. WHAT WON THIS WEEK? (Which single piece of content led in reach &    │
│    follows? What was the underlying emotional or clinical trigger?)     │
│ 2. WHAT LOST THIS WEEK? (Which piece fell below median? Why did the     │
│    hook fail to hold audience at 3 seconds?)                            │
│ 3. WHICH HOOK FORMULA WON? (Curiosity vs Question vs Pattern Interrupt?)│
│ 4. WHICH SPEAKER WON? (Dr. Atul Madaan vs OT vs Speech vs Collab?)      │
│ 5. WHICH TOPIC WON? (Diagnostic signs vs Sensory Hacks vs School Law?)  │
│ 6. WHICH VIDEO DURATION WON? (Sub-30s vs 30-45s vs 60s+?)               │
│ 7. WHICH CENTRE CONTENT RESONATED? (Delhi EOK vs Faridabad vs Ludhiana?)│
│ 8. WHICH LANGUAGE MIX PERFORMED BEST? (Hindi vs Hinglish vs English?)   │
│ 9. WHICH CTA WON? (DM 'CHECKLIST' vs Call Helpline vs Save Post?)       │
│ 10. WHICH CONTENT GENERATED FOLLOWS VS. JUST VANITY VIEWS?              │
│ 11. WHICH REELS QUALIFY FOR META AD SCALING (GREEN MATRIX)?             │
│ 12. WHICH WINNING TOPIC SHOULD BE RE-RECORDED WITH A NEW HOOK?          │
│ 13. WHAT SHOULD WE STOP DOING EFFECTIVE TODAY?                          │
│ 14. HOW MANY INQUIRIES CONVERTED INTO IN-PERSON CENTRE VISITS?          │
└─────────────────────────────────────────────────────────────────────────┘
```

## 3. The 4-Phase 60-Day Optimization Engine

We do not wait until Day 60 to evaluate success. The 60-day campaign is divided into four distinct 2-week execution sprints:

```
  WEEKS 1–2:             WEEKS 3–4:             WEEKS 5–6:             WEEKS 7–8:
   TESTING &             PATTERN                SCALE &                LOCAL DOMINANCE &
   CALIBRATION           RECOGNITION            AMPLIFICATION          CONVERSION
┌───────────────┐      ┌───────────────┐      ┌───────────────┐      ┌───────────────┐
│ • Test 14     │      │ • Identify top│      │ • Double down │      │ • Heavy geo-  │
│   diverse     │      │   3 hook      │      │   on top 20%  │      │   fenced ad   │
│   hooks       │ ───► │   patterns    │ ───► │   winning     │ ───► │   saturation  │
│ • Benchmark   │      │ • First guest │      │   creative    │      │ • Launch final│
│   organic     │      │   collab Live │      │ • Scale Meta  │      │   PTP cohort  │
│   medians     │      │ • Adjust      │      │   winner ads  │      │ • Review 60-  │
│ • Establish   │      │   budget to   │      │ • Launch 2nd  │      │   day growth  │
│   paid base   │      │   winning geos│      │   guest Live  │      │   & Year-2 plan│
└───────────────┘      └───────────────┘      └───────────────┘      └───────────────┘
```

### Phase 1: Weeks 1–2 (Testing & Creative Calibration)
*   **Primary Focus:** Broad testing of speakers, hook archetypes, and centre backdrops.
*   **Tactical Actions:**
    *   Publish 14 short-form Reels across all 10 core pillars.
    *   Calculate real account medians for 3-second hold rate and share rate.
    *   Initiate baseline local Google Search campaign (₹1,000/day).
    *   Test initial cold reach Advantage+ ad set in Delhi EOK (8km) and Faridabad (10km).

### Phase 2: Weeks 3–4 (Pattern Recognition & Optimization)
*   **Primary Focus:** Double down on winning topics; eliminate underperforming formats.
*   **Tactical Actions:**
    *   Identify the top 20% Reels from Weeks 1–2; activate the 24-Hour Organic-to-Paid scaling rule.
    *   Host Live Broadcast 1 with guest South Delhi Pediatrician.
    *   Analyze profile-visit-to-follow conversion rate; optimize Instagram bio, pinned posts, and Story highlights.
    *   Conduct first center B-roll refresh for East of Kailash and Faridabad.

### Phase 3: Weeks 5–6 (Scale & Cross-Pollination)
*   **Primary Focus:** Aggressive follower scaling and collaboration activation.
*   **Tactical Actions:**
    *   Ramp Meta Ads spend to peak daily run-rate (₹5,000–₹6,500/day).
    *   Publish joint collaborative Reels with mom creators and school partners.
    *   Host Live Broadcast 2 (Therapist Room Live Tour) and Live Broadcast 3 (School Inclusion).
    *   Begin re-recording winning topics with alternate hook variations.

### Phase 4: Weeks 7–8 (Local Dominance & Commercial Conversion)
*   **Primary Focus:** Translating online brand recognition into physical centre appointments.
*   **Tactical Actions:**
    *   Deploy heavy geo-radius walkthrough video ads for East of Kailash and Faridabad Crown Plaza.
    *   Host Live Broadcast 4 with prominent parenting creator.
    *   Retarget 100% of 60-day video viewers with the *Parent Training Program (PTP)* enrollment prompt.
    *   Compile the comprehensive 60-Day Final ROI Report for Autism Alliance leadership.
